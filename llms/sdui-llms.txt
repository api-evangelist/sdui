# Sdui

> Sdui GmbH (Koblenz, Germany; part of the Sdui Group / Seven Education) builds GDPR-compliant digital
> communication, organisation and administration software for schools, preschools and school
> authorities in Germany, Switzerland, France and Spain. Sdui runs a production JSON API that powers
> its own apps and its WebUntis messenger integration, but publishes no public developer portal, API
> reference or machine-readable specification.

This file was generated by API Evangelist from probed evidence. Sdui does not publish an llms.txt
(https://sdui.de/llms.txt returns HTTP 404). Nothing below is inferred: every statement is either read
from a document Sdui serves or observed on a live unauthenticated request on 2026-08-26.

## What an agent can and cannot do here

- There is NO OpenAPI, Swagger, GraphQL SDL, AsyncAPI, Protobuf or WSDL on any Sdui host. Probed
  /openapi.json, /openapi.yaml, /swagger.json, /api-docs, /docs, /redoc, /v1/openapi.json and
  /graphql on api.sdui.app — all 404.
- The Sdui Platform API at https://api.sdui.app/v1 is real and live, but every resource is
  authenticated. It answers `WWW-Authenticate: Bearer` and returns HTTP 401 with the German string
  "Bitte zuerst einloggen." Token issuance is not publicly documented.
- One endpoint answers anonymously: GET https://api.sdui.app/v1/status returns deployment metadata
  (mode, allowed origin targets, pod name, release commit SHA).
- Sdui DOES serve a remotely-callable MCP server, but it belongs to the WordPress marketing site, not
  the school platform: https://sdui.de/wp-json/mcp/mcp-oauth-server (OAuth, HTTP 401 anonymous).
- No A2A agent card exists on any host. sdui.app answers HTTP 200 with its SPA HTML shell for every
  /.well-known/* path; that is not a document.

## Machine-readable documents Sdui actually serves

- [OAuth authorization server metadata](https://sdui.de/.well-known/oauth-authorization-server): RFC 8414. authorization_code + refresh_token, PKCE S256, scope `mcp`, public clients.
- [OAuth protected resource metadata](https://sdui.de/.well-known/oauth-protected-resource): RFC 9728. Names the MCP endpoint and the `mcp` scope.
- [security.txt](https://sdui.app/.well-known/security.txt): RFC 9116. security@sdui.de, policy URL, Expires 2027-02-23.

## Integrations

Sdui's integrations are bilateral and proprietary — no education interoperability standard (OneRoster,
LTI, Ed-Fi, SIF, SCIM) is declared on any contract or page.

- [WebUntis / Untis](https://sdui.de/sdui-untis-kooperation/): the Sdui Messenger inside WebUntis; users and classes sync from WebUntis within six hours. Partner contact untis@sdui.de.
- Stüber Systems (DAVINCI, ENBREA): timetable interface; digital class register integration in progress.
- Moodle and other LMS products: embedded at the menu level.
